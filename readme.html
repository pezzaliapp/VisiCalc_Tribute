🧮 VisiCalc Tribute — README

Che cos'è

Un foglio elettronico minimale, ispirato a VisiCalc, offline-ready e salvato in locale.

Funzioni

  • Griglia A..Z × 50 righe
  • Formule: =A1+B2, operatori + - * /, parentesi
  • Intervalli e SUM(A1:B3)
  • Export/Import CSV
  • PWA con Service Worker

Note tecniche

Engine formule molto semplice: ogni modifica ricalcola l'intero foglio; i riferimenti non numerici valgono 0.
