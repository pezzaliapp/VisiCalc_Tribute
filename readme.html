🧮 VisiCalc Tribute — README

Cos'è

Un foglio elettronico minimale e veloce, ispirato a VisiCalc. Funziona anche offline (PWA).

Funzioni principali

  • Griglia A..Z × 50 righe
  • Formule con operatori + - * / ( ) e riferimenti A1, $A$1, A$1, $A1
  • Funzioni: SUM, AVERAGE, MIN, MAX, IF, VLOOKUP (alias CERCA_VERT)
  • Intervalli rettangolari: es. A1:B3
  • CSV import/export
  • UI Mobile: tastierino numerico/simboli, lettere A–Z, frecce, Enter, rotazione

Esempi rapidi

=A1+B1
=SUM(A1:B3)
=AVERAGE(A1:B3)
=IF(A1>10, "ALTO", "BASSO")
=VLOOKUP(A1, A1:B9, 2, TRUE)

Note

  • I valori testuali in operazioni sono trattati come 0.
  • Numeri con virgola (es. 3,5) accettati (trasformati in punto).
  • Gli intervalli devono essere continui e rettangolari.
